Busca de Usuários

Projeto desenvolvido para praticar JavaScript, consumo de API, manipulação do DOM e tratamento de erros.

Funcionalidades

Carregamento de usuários de uma API.

Exibição de nomes, usernames e e-mails.

Pesquisa de usuários por nome.

Busca parcial, sem distinção entre maiúsculas e minúsculas.

Armazenamento e recuperação de dados com LocalStorage.

Tratamento de erros de requisição e respostas HTTP.

Tecnologias utilizadas

HTML5

CSS3

JavaScript

Fetch API

Async/Await

LocalStorage

API utilizada

JSONPlaceholder

Como executar

Clone ou baixe este repositório.

Abra o arquivo index.html no navegador.

Clique em Carregar usuários.

Digite um nome no campo de pesquisa e clique em Buscar.

É necessária uma conexão com a internet para carregar os usuários da API quando ainda não existem dados salvos no navegador.

Objetivo

Este projeto faz parte dos meus estudos de JavaScript e representa mais uma etapa do meu aprendizado em desenvolvimento web, com foco futuro em desenvolvimento back-end.
